# Local validation

Run the frozen install, `pnpm check` and `pnpm build` from the repository root. The canonical origin defaults to `https://kerisjambi.com` in `astro.config.mjs` and may be overridden for a preview.

Check every Indonesian/English guide and legal-page pair for unique metadata, self canonical URLs, topic language alternates, internal links and assets. Visible FAQs and FAQ structured data share one source. The error page is noindex and excluded from the sitemap.

The Worker runs before ASSETS, redirects HTTP/www to the HTTPS apex while preserving paths and queries, and retains real 404 responses with noindex. Production build identity, domain bindings and rendered pages require verification after release.
